# 🏠 かんたんな家計簿 (simple_kakeibo)

**「世界一使いやすい」を目指して開発している、シンプル機能の家計簿アプリです。**
使用してみての感想やアドバイスなども心からお待ちしてます！

---

## 🌟 特徴
- **直感的な操作**: 迷わずすぐに金額を入力できます。
- **簡易電卓内蔵**: アプリを閉じずに計算してそのまま入力可能。
- **柔軟なタブ管理**: 最大3つまでタブを増やせ、名前も自由に変更できます。
- **ダークモード対応**: 最新のディスプレイでも目に優しいデザイン。

## 🚀 インストール方法 (Android)
1. GitHubリポジトリ右側の **[Releases]** をクリックします。
2. 最新バージョンの `app-release.apk` をダウンロードします。
3. Android端末でファイルを開き、インストールしてください。
   ※自作アプリのためインストール時に警告が出ることもありますが、許可して進めてください。
